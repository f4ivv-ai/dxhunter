# DX Hunter — Identité de conception

Application web temps réel de traque des spots DX pour radioamateur, optimisée SSB (10/15/20/40/80/160 m), CW en secondaire.

## Trois directions stylistiques envisagées

### 1. Station Tactique (Tactical Radio Room)
Esthétique de poste de commandement / cockpit opérateur : fond très sombre, accents ambrés et verts phosphore type oscilloscope, typographie monospace technique.
Probabilité : 0.07

### 2. Atlas Propagation (Cartographie scientifique)
Inspiration cartes ionosphériques, tons sépia/bleu nuit, lignes de propagation élégantes.
Probabilité : 0.04

### 3. Néon Contest (Pile-up moderne)
Tons néon cyan/magenta sur fond charbon, énergie de contest.
Probabilité : 0.03

## Direction retenue : Station Tactique (Tactical Radio Room)

- Design Movement : UI industrielle inspirée des transceivers modernes (Icom/Elecraft) et consoles SDR (waterfall), croisée avec le "terminal aesthetic".
- Core Principles :
  1. Densité d'information maîtrisée : voir beaucoup de spots lisibles d'un coup.
  2. Hiérarchie par la couleur : le SSB ressort, le CW reste discret.
  3. Lisibilité en shack sombre : fond sombre, fort contraste.
  4. Réactivité temps réel : nouveaux spots animés sans distraire.
- Color Philosophy : Fond charbon/anthracite. Accent ambre signal (#FFB000). Vert phosphore pour SSB prioritaire, bleu acier pour CW/digi. Rouge alerte pour DX rares.
- Layout Paradigm : Dashboard dense — filtres à gauche, flux de spots central, carte/stats à droite. Pas de layout centré.
- Signature Elements : Bandeau d'état type "rig" (UTC, état connexion, compteur), badges de bande monospace, indicateur LIVE pulsé.
- Interaction Philosophy : Filtrage instantané, survol spot = surbrillance carte.
- Animation : Entrées de spots fondu + glissement (<200ms ease-out). Pulsation LIVE.
- Typography System : JetBrains Mono (fréquences/badges), Space Grotesk (libellés UI).
- Brand Essence : « Le radar DX du shack ». Adjectifs : précis, vigilant, technique.
- Brand Voice : Direct, jargon radio. Ex : « 14 spots SSB actifs sur 20 m ».
- Wordmark & Logo : Onde radio traversant un réticule en ambre, sans texte.
- Signature Brand Color : Ambre signal #FFB000.
