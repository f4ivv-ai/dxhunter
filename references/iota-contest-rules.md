# RSGB IOTA Contest 2025 — Rules Summary

## Date
Saturday 26 July - Sunday 27 July 2025, 1200-1200 UTC (24h)

## Bands
3.5, 7, 14, 21, 28 MHz (80/40/20/15/10m)

## Modes
CW and/or SSB

## Categories
- World Station (not on island): Single Op only
- Island Station - Fixed
- Island Station - DXpedition
- SO Unassisted / SO Assisted / Multi-1 / Multi-2

## Exchange
- World Stations: RST + serial number (ex: 599 254)
- Island Stations: RST + serial number + IOTA Reference (ex: 59 378 EU115)

## Scoring (QSO Points)
### As World Station (F4IVV):
- Contact World Station: 2 points
- Contact Island Station: 15 points

### As Island Station:
- Contact World Station: 5 points
- Contact Island Station same IOTA ref: 5 points
- Contact other Island Station: 15 points

## Multipliers
- Each different IOTA reference contacted, per band, per mode (CW/SSB separately)
- Total Score = (sum QSO points all bands) × (sum multipliers all bands)

## IOTA Reference Format
- XX-NNN (e.g., EU-005, AF-032, NA-001, SA-015, OC-001, AS-007, AN-001)
- XX = continent prefix (EU, AF, NA, SA, OC, AS, AN)
- NNN = 3-digit number

## Key Points for DX Hunter Implementation
- F4IVV is a World Station (not on island)
- Main value: contact Island Stations (15 pts each)
- Multipliers = unique IOTA refs per band per mode
- Need to extract IOTA ref from spot comments or exchange
- Spots with IOTA refs in comments are high-value targets
- Cabrillo export needed for submission (within 5 days)
