# Recherche Multiplicateurs par Concours

## 1. CQ WPX (SSB mars, CW mai)
- **Multiplicateur** : Préfixes (le préfixe du call sign)
- Chaque PRÉFIXE est compté une seule fois, toutes bandes confondues
- Ex: N8, W8, WD8, HG1, HG19, KC2, OE2, OE25, LY1000
- Portable : le préfixe portable devient le multiplicateur (PA/N8BJQ → PA0)
- Score = QSO points × nombre de préfixes différents travaillés

## 2. CQ WW DX (SSB octobre, CW novembre)
- **Multiplicateurs** : Zones CQ + Pays DXCC, par bande
- Zone : 1 mult par zone CQ différente contactée, par bande (40 zones CQ)
- Pays : 1 mult par pays DXCC différent contacté, par bande (liste DXCC + WAE)
- Score = QSO points × (total zones + total pays)

## 3. IARU HF Championship (juillet, TM0HQ pour la France)
- **Multiplicateurs** : Zones ITU + stations HQ IARU, par bande (pas par mode)
- Zone ITU : 1 mult par zone ITU différente, par bande (90 zones ITU)
- Stations HQ : chaque station HQ IARU (TM0HQ, W1AW, GR2HQ, etc.) = 1 mult par bande
- Officials IARU : AC, R1, R2, R3 = max 4 mults par bande
- Les stations HQ/officials ne comptent PAS pour les zones
- Score = QSO points × total multiplicateurs

## 4. Coupe du REF (CW janvier, SSB février)
- **Multiplicateurs pour stations non-françaises** :
  - Départements français métropolitains (97 + Corse) + F6REF/00, une fois par bande
  - DOM/TOM français
- **Multiplicateurs pour stations françaises** :
  - Départements + DOM/TOM, une fois par bande
  - Pays DXCC non-français, une fois par bande
- Bandes : 80, 40, 20, 15, 10m
- Score = QSO points × total mults
